# Security policy

herdr-fleet is not sandboxed. Herdr plugins run with your user's privileges, so review the source before installing. See "Privacy and trust" in the README for what this plugin reads and runs.

## Reporting a vulnerability

Please report privately through GitHub security advisories ("Security" tab, "Report a vulnerability") on this repository. Do not open a public issue for security problems, and do not include real pane output, titles, paths or session identifiers in reports.

Only the latest released version is supported.
